How to Install & Run

🔑 Step 1: Obtain a Free API Key

What is an API Key? Think of it as a secure, free ID card that tells Google you are authorized to talk to their AI. You only have to get this once!

1. Go to aistudio.google.com and sign in with your normal Google account.

2. Click the "Get API key" button on the left side of the screen.

3. Choose the Free tier (which provides plenty of usage for a single person).

4. Copy the long text password it gives you. You will paste this directly into the top of the BenevolentGemini app.

🪟 For Windows Users


The Easy Way (Recommended)

You don't need to know anything about coding. Just scroll up to the top of this page and click the "Windows Download (.exe)" button. Once downloaded, double-click the file to open the app instantly.



The Python Way (For Developers)

If you prefer running the raw code:

1. Install Python from python.org (ensure "Add to PATH" is checked).

2. Open Command Prompt and type:

pip install PyQt5 pillow google-genai

3. Run the script:

python BenevolentGemini.py

🐧 For Linux & Raspberry Pi

Because Linux systems are all built slightly differently, you need to run the raw Python code. Just open your Terminal (the black command window) and paste these commands exactly as shown.

1. Install the Visual Display Tools

sudo apt update
sudo apt install python3-pyqt5 python3-pip

2. Install the Brain & Memory Tools

pip3 install pillow google-genai

*If your system gives an "environment" error, just add --break-system-packages to the end of that command.

3. Start the App

python3 BenevolentGemini.py

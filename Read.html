BenevolentGemini

A lightning-fast, zero-bloat AI client for Windows, Linux & Raspberry Pi.

Made by Dr. Bishnu Goswami

🔑 Step 1: Get Your API Key

Before running the app, you need a key to connect to Google's AI servers.

  • Visit aistudio.google.com and sign in with your Google account.
  • Click "Get API key" in the left-hand navigation menu.
  • Choose the Free Tier (generous limits) or Paid Tier (for heavy processing).
  • Copy your key! You will paste this directly into the BenevolentGemini app menu.
🪟 Windows

Option A: The Easy Way

Simply download the BenevolentGemini.exe file and double-click it. No installation required!

Option B: Python (For Devs)

1. Install Python (Check "Add to PATH").

2. Open Command Prompt and run:

pip install PyQt5 pillow google-genai

3. Launch the app:

python gemini_gui.py
🐧 Linux & Pi 3+

Native performance requires native libraries. Install them via your terminal.


1. Install GUI Libraries

sudo apt update
sudo apt install python3-pyqt5 python3-pip

2. Install Python Tools

pip3 install pillow google-genai

*If you get an environment error, add --break-system-packages


3. Launch the App

python3 gemini_gui.py
